# Demo Video Script — GlanceTrade (≤ 3 minutes)

Recorded during build week (28 Nov) in the Even Hub simulator.
Format: screen recording of the simulator window + voiceover (English).
Target length: **2:30–2:50**. Every shot shows the real app running —
no mockups, no slides of fake UI.

## Recording notes

- Record the simulator window at the largest clean size; the 576×288
  canvas is small — crop tight, do not upscale with blur.
- If simulator mic input is unreliable on the recording machine, use the
  typed-command fallback for the voice shots and say in the voiceover
  that voice runs through the same parser (honest, no faked audio).
- Show one real price refresh happening (wait for the 45 s cache cycle
  or trigger a manual refresh) so judges see live data, not a screenshot.
- Keep the end card on screen for at least 5 seconds with the repo URL
  readable.
- Upload as unlisted YouTube or Loom (user's account); paste the link
  into the README and the submission draft.
